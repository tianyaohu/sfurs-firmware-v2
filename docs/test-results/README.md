# Hardware test results

One file per test session: `YYYY-MM-DD-topic.md`. Facts only; keep each short.

```
# <topic>  (date, who)
- Firmware: commit, ESC/Nucleo image hashes
- Setup: wheels raised or ground, battery V, floor, probe/CAN
- Procedure: command or script run
- Result: numbers, pass/fail against the PRD acceptance line
- Data: path to raw capture (kept outside git), if any
```

Conclusions that change future behaviour also go as one line in
[../LESSONS.md](../LESSONS.md).
