# B-G431B-ESC1 wheel controller firmware

- `motor_config/`: the application (ST MCSDK 6.4.1 project generated by
  Motor Control Workbench from `motor_config.stwb6`, plus our code).
- `bootloader/`: CAN bootloader ([README](bootloader/README.md)).
- `Inc/motor_controller_can.h`: maps the `MOTOR_NE|SE|SW|NW` build macro to
  the CAN select bit.
- `bldc_24V_9.5Apk.json`: older Workbench motor profile kept for reference.
- `motor_config/Drivers/CMSIS/DSP` keeps only `Include/` (on the include
  path; no DSP functions are linked). Workbench regeneration may restore the
  rest; delete it again.

## Build

```sh
../../scripts/esc_build.sh --motor NE --app-offset --output /tmp/esc-NE [--hall-shift DEG]
```

Exactly one wheel macro per build. `--app-offset` links at `0x08004000`
under the CAN bootloader (the only layout in use). `scripts/build.sh`
builds all four plus the Nucleo images.

## What is ours vs generated

Ours: `Src/drive_app.c`, `Inc/drive_app.h` (application glue on MCSDK, see
`architecture/drive.md`), `Src/motor_cmd.c` / `Inc/motor_cmd.h` (command lifecycle) and
`Src/motor_speed.c` / `Inc/motor_speed.h` (speed loop), the `USER CODE` sections of
`Src/main.c`, the angle and capture hooks in `FOC_CurrControllerM1` (`Src/mc_tasks_foc.c`),
the `USER` Hall edge counters `EdgesPos`/`EdgesNeg` in `hall_speed_pos_fdbk.h/.c`, and
parameter edits in `Inc/drive_parameters.h`, `Inc/pmsm_motor_parameters.h` and
`SPEED_UNIT` in `Inc/mc_stm_types.h`. Everything else is MCSDK/CubeMX output.

Regenerating from Workbench overwrites the parameter headers: re-apply the
values listed in `architecture/drive.md` (speed-loop gains and stall defaults, 8 A, `U_RPM`,
Hall FIFO depth 6, OV 18 V, default speed 0) and keep the `drive_app.c`, `motor_cmd.c` and
`motor_speed.c` links in `STM32CubeIDE/.project` (the build itself uses
`scripts/esc_sources.txt`).

## CAN timing

FDCAN at 500 kbit/s nominal, FD frames without BRS. Keep the generated
`MX_FDCAN1_Init` values; they match the Nucleo. NE and SE drive PC14 high to
enable the bus termination resistor; SW and NW leave it off.
